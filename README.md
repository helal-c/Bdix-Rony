# Bdix-Rony CloudStream Repository

A clean CloudStream extension repository structure for the Movie / FTP sources supplied by the repository owner.

## Important
This repository is a **provider scaffold**. Each provider contains its source URL and a safe placeholder implementation. 
Before enabling a provider for public use, implement and test the site's parser/API integration and make sure you have permission to access and redistribute the site's content.

## Structure

- `providers/` — one provider folder per source
- `docs/` — repository documentation
- `builds/repo.json` — repository manifest
- `.github/workflows/` — CI placeholder

See `builds/repo.json` for the complete source list.
